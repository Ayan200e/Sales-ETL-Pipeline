# Sales-ETL-Pipeline
●	Architected and executed an end-to-end ETL pipeline to extract raw sales datasets from CSV files, applying automated data cleaning transformations including duplicate removal and missing value imputation via Scikit-learn's SimpleImputer.
●	Integrated Python's native logging framework configured with clear INFO and ERROR levels to facilitate comprehensive performance monitoring, runtime debugging, and seamless error tracing while maintaining production-clean terminal outputs.
●	Engineered the target database layer using SQLite, implementing optimized schemas to load clean structured data and designing aggregate SQL queries to generate strategic business reports.
